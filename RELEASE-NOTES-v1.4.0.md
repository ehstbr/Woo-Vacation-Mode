# Woo Vacation Mode Basic v1.4.0

Initial public release of **Woo Vacation Mode Basic**.

A lightweight way to temporarily pause purchases in WooCommerce without taking the storefront offline.

## Highlights

- Full-width vacation notice at the top or bottom of the site.
- WYSIWYG editor for the main notice.
- Configurable notice colors.
- Optional dismiss button with configurable redisplay time.
- Hide purchase buttons while vacation mode is active.
- Custom replacement message in the purchase-button area.
- Separate cart and checkout notice.
- WooCommerce-level purchase blocking.
- English source language with Brazilian Portuguese translation included.
- UTF-8 `.po` / `.mo` files and translation-ready `.pot`.
- Native WordPress admin interface.
- Open source under **GPL v3 or later**.

## Repository

https://github.com/ehstbr/Woo-Vacation-Mode

## Installation

Download `woo-vacation-mode-basic-v1.4.0.zip`, upload it through **Plugins > Add New > Upload Plugin**, activate it, and open **WooCommerce > Vacation mode**.

## Português do Brasil

Primeira versão pública do **Woo Vacation Mode Basic**.

O plugin permite colocar uma loja WooCommerce em modo férias sem tirar a vitrine do ar, informando os clientes e bloqueando novos pedidos enquanto o modo estiver ativo.

### Principais recursos

- aviso em largura total no topo ou rodapé;
- WYSIWYG para a mensagem principal;
- cores personalizáveis;
- botão de fechar opcional com reexibição configurável;
- ocultação dos botões de compra;
- texto personalizado na área dos controles de compra;
- mensagem independente para carrinho e checkout;
- bloqueio de novas compras pelo WooCommerce;
- tradução PT-BR incluída em UTF-8;
- arquivo `.pot` para novas traduções;
- interface administrativa nativa do WordPress;
- licença **GPL v3 ou posterior**.
